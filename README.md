# Dungeon Survivor — Foundation 0.4

A deliberately stripped-back first build based on the fresh Foundation 0.4 source documents.

Core loop: move -> fight -> kill -> physically collect gold -> clear room -> room artwork switches to open door -> walk through north exit -> next test room.

This build intentionally excludes merchants, treasure rooms, bosses, elites, procedural generation and hidden/inferred collision.

Godot target: 4.7.x.
