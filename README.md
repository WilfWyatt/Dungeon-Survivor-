# Dungeon Survivor

A mobile-first HTML/JavaScript roguelite prototype.

## Current build
- Move with the on-screen joystick.
- Player automatically targets and shoots the nearest enemy while FIRE is held.
- Clear enemies from a room.
- Enemies drop physical loot on the floor.
- Loot must be walked over to collect it.
- Pickup notification appears when loot drops/gets collected.
- Once the room is clear, an EXIT appears and the next room loads.
- Increasing enemy difficulty.
- Health, kills and basic upgrade/potion/coin/ammo loot types.
- GitHub Pages/PWA-ready.

## GitHub Pages
Upload all files to a GitHub repository, then:
Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
Open the generated Pages URL in Chrome on Android and use Chrome's menu -> Add to Home screen / Install app.
